# java-lotto-precourse
## 개인적인 목표

1. [README.md](http://README.md) 를 지속적으로 업데이트하여 살아있는 문서로 만들기
2. 테스트 코드 작성에 대한 장점을 몸소 느끼기
3. 요구사항인 enum을 활용하여 하드 코딩을 하지 않기

## 과제 설명

로또를 원하는 만큼 구입하고 당첨 여부와 수익률을 확인한다.

## 기능 목록

📍**금액 입력**

- [ ]  사용자에게 로또를 얼마치 살지 입력받는다.
    - 로또 한장의 금액은 1000원이다.
- [ ]  사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.
    - 사용자가 문자나 음의 정수를 입력할 경우
    - 1000원으로 나누어 떨어지지 않는 경우

📍**로또 번호 추첨**

- [ ]  로또 수량만큼 번호를 랜덤으로 추첨한다.

📍**로또 출력**

- [ ]  번호를 오름차순으로 출력하다.

📍**당첨 번호 입력**

- [ ]  사용자가 당첨번호 6개를 쉼표로 구분하여 입력한다.
    - 6개 중 중복이 있는지 확인한다.
- [ ]  사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.
    - 사용자가 1부터 45 이외의 숫자나 문자를 입력할 경우
- [ ]  보너스 번호를 입력한다.
    - 보너스 번호가 이전 당첨번호 6개와 중복되는지 확인한다.

📍**당첨 여부 확인**

- [ ]  일치하는 개수마다 사용자가 입력한 당첨 번호의 숫자가 추첨한 로또 번호와 몇개가 일치하는지 확인한다.
    - 필요시 보너스 볼의 일치여부를 확인한다.

📍**당첨 여부 출력**

- [ ]  명세에 맞게 당첨 여부를 출력한다.

📍**수익률 계산**

- [ ]  수익률 (당첨 금액 /로또 구매 금액 * 100) 을 계산한다.

📍**수익률 출력**

- [ ]  수익률을 출력한다.
